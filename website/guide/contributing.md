# Contributing

From a first issue to owning a protocol surface — the path is open and
intentional.

<p align="center">
  <img src="/diagrams/contributor-path.svg" alt="Contributor path" style="width:100%;border:1px solid #1e2430;border-radius:12px" />
</p>

| Step | Do this |
| --- | --- |
| Start Here | Read the README and [Concepts](/guide/concepts). |
| Good First Issue | Pick a small, scoped task labeled `status: good first issue`. |
| Protocol RFC | Propose a change via an [RFC](/guide/rfcs). |
| Runtime Implementation | Build enforcement at a real surface. |
| Docs + Examples | Teach the next developer. |
| Maintainer Path | Own a protocol surface. |

See [CONTRIBUTING.md](https://github.com/BlockSiFr/ttp-protocol/blob/main/CONTRIBUTING.md)
and [GOVERNANCE.md](https://github.com/BlockSiFr/ttp-protocol/blob/main/GOVERNANCE.md).
